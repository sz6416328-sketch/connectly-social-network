# 🌐 Connectly — Social Network Platform

Connectly is a modern, responsive social networking platform built using **HTML, CSS, and JavaScript**.

The project provides a clean and interactive social media experience where users can create posts, interact with content, view profiles, manage privacy settings, and explore trending content.

## ✨ Features

- 👤 User Profile
- 📝 Create Posts
- ❤️ Like Posts
- 💬 Comment System
- 🔗 Share Posts
- 🗑️ Delete Posts
- 🖼️ Image Upload for Posts
- 📱 Fully Responsive Design
- 🌙 Dark Mode
- 🔔 Notifications UI
- 👥 Friend Suggestions
- 🟢 Online Friends Section
- 🔥 Trending Topics
- 🔐 Privacy Settings
- ⚙️ User Settings
- 💾 Local Storage Support
- 🔔 Toast Notifications
- 📱 Mobile-Friendly Interface
